# 产品需求规格说明书 (PRD) — 3D 中医经络穴位教学系统

## 1. 项目背景与目标
本项目旨在为中医专业学生及教师提供一套直观、精确、可交互的 Web 端 3D 人体经络穴位演示系统。
* **核心定位**：服务于本科《针灸学》课堂演示与学生自主复习。
* **精度标准**：穴位名称、国际代码与体表定位严格遵循国家标准 **GB/T 12346-2021《经穴名称与定位》**。
* **实施策略**：复用开源项目 `aicuc/3d-acupoint-atlas`（MIT License）的 3D 人体模型及现有坐标作为初稿（Draft），通过内置 3D 表面标定工具逐一按国标复核微调。

## 4. 功能需求清单

### 4.1 3D 人体交互与视图控制 (P0)
* **基础操控**：支持 360° 自由旋转、缩放、平移；支持一键重置至标准解剖学正面/背面/侧面视角。
* **智能聚焦**：点击任意穴位（或通过搜索选中）时，3D 相机平滑过渡至该穴位的最佳观察角度（`cameraPreset`）。
* **模型透明度/辅助显示（P1）**：支持调整人体模型材质透明度或线框模式，便于观察深层或对侧经络。

### 4.2 经络循行可视化 (P0)
* **分经管理**：支持十四经脉（十二正经 + 任脉、督脉）的独立开关、全选、清空与高亮聚焦。
* **防穿模贴肤路径**：经络线需贴合 3D 人体表面走向，避免穿透模型内部。
* **动态流向演示（P1）**：支持沿经络循行方向播放气血流动动画，直观呈现手足三阴三阳交接规律。

### 4.3 穴位精确标识与详情面板 (P0)
* **空间标识**：穴位点垂直贴合皮肤表面（基于表面法向量），点击高亮并展示详情卡片。
* **结构化知识卡片**：
  * **标准信息**：GB/T 12346-2021 标准代码（如 `LU9`）、中文名、拼音、所属经络、特定穴属性（五输穴、原穴、络穴、募穴、背俞穴、八会穴等）。
  * **名解与由来**：穴位名称含义解析、最早记载典籍出处（如《灵枢》《针灸甲乙经》）。
  * **精准定位**：GB/T 12346-2021 标准定位原文 + 临床简便取穴法。
  * **临床应用**：核心功效、主治病症、常规刺灸法及操作禁忌。

### 4.4 检索与教学辅助 (P1)
* **多维检索**：支持按穴位名、拼音/首字母、国标代码、主治症状关键词实时搜索并定位。
* **特定穴筛选**：支持一键高亮全人体或当前经络下的特定穴分类。
* **教学盲测模式**：开启后隐藏所有穴位名称标签；用户点击 3D 模型上的穴位点后，弹窗或面板揭示答案，用于课堂抽查与自测。

### 4.5 开发态：初稿导入与国标复核工具 (P0 - 仅开发环境)
* **复核状态可视化**：在 3D 模型上用颜色区分未复核初稿（`draft_imported`）与已校准穴位（`gb_verified`）。
* **3D 表面重打点**：选中待复核穴位后，直接点击 3D 人体模型正确解剖位置，自动捕获三维坐标 `position`、表面法向量 `normal` 及当前最佳 `cameraPreset`，支持一键导出更新后的 JSON。

## 5. 非功能性需求
* **全端响应式**：
  * **桌面端 (`>= 1024px`)**：左侧经络目录与筛选 + 中间 3D 主画布 + 右侧穴位详情面板。
  * **移动端 (`< 768px`)**：全屏沉浸式 3D 画布 + 顶部悬浮搜索与视角按钮 + 底部可拖拽抽屉（Bottom Sheet）；优化触控拾取半径，防止手指误触。
* **性能基线**：移动端限制最大像素比（`devicePixelRatio <= 2`），保证中端手机流畅旋转不卡顿。
* **可扩展性**：纯静态数据驱动，新增经外奇穴、临床配穴方案或切换多语言时，仅需扩充 JSON 数据，无需修改渲染引擎。
* **离线打包预留**：首期以标准 Web 工程开发与 GitHub Pages 部署为主，但资产加载层需保持解耦，为后续“单文件离线 HTML 双击运行”优化留出扩展点。

## 6. 分期内容范围
* **Phase 1 (MVP)**：跑通 3D 骨架、上游坐标导入、3D 复核工具及**手太阴肺经（11 穴）**完整教学闭环。
* **Phase 2 (核心教学版)**：覆盖本科《针灸学》教材十四经脉重点常用穴（约 120–160 穴）的文本录入与 GB/T 12346-2021 坐标复核。
* **Phase 3 (全量与增强版)**：补全十四经脉全部 361 穴、上线盲测模式与经络流向动画、推进 Draco 压缩与单文件离线打包方案。
